# Day-job card photos
Drop GPT's pictures here with these exact names (PNG):
- `hospital.png`, `steel.png`, `textile.png`

The card shows the photo at about 4:3.5 (wide x tall), cropped from the centre to fill, so any size works;
about 820 x 720 px or larger looks sharp. Pixel-art style like the mockup (dark, warm lamp light).
Open the project in Godot once after adding them so they get imported. Until then a "PHOTO" placeholder shows.
The card text lives in data/v2/economy.json under jobs.<id>.card.
